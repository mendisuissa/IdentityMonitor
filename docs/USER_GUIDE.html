Alerts — Active Threats

Security
identitymonitor.modernendpoint.tech/alerts
⚡ Alerts

🎯 סינון מתקדם

סינון לפי Status (Open/Assigned/Resolved) ו-Severity (Critical/High/Medium). חיפוש חופשי לפי משתמש, IP, מדינה, אפליקציה.

🏷️ תיוג אוטומטי

כל alert מקבל Severity badge (CRITICAL/HIGH/MEDIUM) ו-Confidence badge (HIGH/MEDIUM CONFIDENCE) אוטומטית לפי אלגוריתם הזיהוי.

👤 Assign & Ownership

הקצאת alert לחבר צוות ספציפי. מעקב אחר בעלות ואחריות. שינוי בעלות מתוך ממשק ה-alert.

✅ Approval Workflow

פעולות קריטיות (Wipe, Block, Reset Password) עוברות Approval flow — מאושר, נדחה, או מוקצה לסגירה.

  • 🔍
    לחיצה על alert — פתיחת פאנל Investigation עם Timeline, Raw data, Evidence ו-Recommended actions
  • 🙋
    Assign to me — לוקח בעלות על alert פתוח
  • ✅
    Approve / Reject — אישור/דחייה של פעולה שדורשת Approval
  • 📌
    Acknowledge — מאשר שהאיום נבדק, מעביר לסטטוס Documented
  • 🔄
    Refresh — טעינה מחדש של התור מה-backend
  • 👑
    Role owner — כפתור ימין עליון — מוסיף Role-based ownership לכל ה-tenant
💡 Alert עם badge HIGH CONFIDENCE = זוהה על ידי מספר אינדיקטורים בו-זמנית (IP חריג + מדינה חדשה + מכשיר לא מוכר). כאלה מחייבים טיפול מיידי.

👥 Exposure

🎯 Privileged Identity Watchlist

טבלה של כל הזהויות בעלות הרשאות גבוהות, ממוינת לפי Risk Score. מציגה Roles, Account state, Open threats.

💥 Blast Radius

🏥 Hygiene Score

ציון היגיינה לכל זהות: MFA, Conditional Access, JIT status, Last sign-in. מזהה חשבונות שיכולים להיות בשימוש מיידי על ידי תוקף.

🎨 Risk Color Coding

CRITICAL (אדום) / HIGH (כתום) / MEDIUM (צהוב) / CLEAN (ירוק). לחיצה על שורה פותחת פאנל פירוט מלא ימינה.

  • 🔍
    חיפוש — חיפוש לפי שם/UPN/Role
  • 👁️
    לחיצה על שורה — פאנל "Exposure Drill" עם threat history, role assignment ו-hygiene signals
  • 📊
    Ordered by risk — מיון לפי Risk Score יורד
⚠️ משתמש עם CRITICAL risk + Enabled account + Global Admin = סיכון מיידי. יש להפעיל Conditional Access Policy או לבצע MFA reset דחוף.

Vulnerability Remediation

סגירת vulnerabilities ישירות מהממשק — ללא כניסה לפורטל אחר

Security
identitymonitor.modernendpoint.tech/remediation
🛠️ Remediation

📋 Vulnerability List

רשימת כל ה-CVEs ו-findings מ-Defender, עם סינון לפי: CVE ID, Product, Publisher, Category, Severity. כולל Remediation required only ו-Exposed devices only.

🗂️ 3 טאבים לכל Finding

Details — פרטי ה-CVE, חומרה, תיאור. Exposed Devices — מכשירים מושפעים. Remediation Plan — תוכנית ביצוע.

🤖 Auto-Remediation (חדש)

תיקון CVEs אוטומטי כל 60 דקות. לחיצת ▶ Run Now מפעילה ריצה מיידית ידנית. התוצאות מופיעות בטאב History. התראת Telegram נשלחת לאחר כל ריצה.

📜 Remediation History

לוג מלא של כל פעולות ה-Remediation — ידניות ואוטומטיות. עמודות: Time, CVE ID, Product, Category, Severity, Status (✅ / ❌ / ⏭), Executor, Message. תוצאה טיפוסית: 250+ פעולות, 98%+ הצלחה.

🤖 Auto-Remediation — איך זה עובד

כל CVE מסווג אוטומטית לאחת מארבע קטגוריות. המערכת פועלת בהתאם — ללא צורך בהתערבות ידנית.

📦 WinGet Applications Auto

אפליקציות צד שלישי (Chrome, Firefox, VS Code, 7-Zip, .NET…) מעודכנות דרך Intune WinGet deployment לכל המכשירים. פריסה שקטה ברקע.

🪟 Windows Updates Auto

תיקוני אבטחה של מערכת הפעלה (Windows Server, Windows 11…) נפרסים דרך Windows Update for Business expedite policy ב-Intune.

🐧 Linux / macOS / iOS Skip

פלטפורמות שאינן Windows מזוהות ומדולגות אוטומטית. הדילוג נרשם ב-History עם הערה. הוראות תיקון ידני מופקות.

🔐 Identity / Conditional Access Skip

findings של זהויות מחייבים בדיקה ידנית של מנהל אבטחה. נרשמים ומדולגים. Auto-Remediation לא מבצעת פעולה על CVEs מסוג Identity.

📱 התראות Telegram

לאחר כל Run Now (ידני) או ריצת cron מתוזמנת, סיכום נשלח לבוט הטלגרם שלך:

  • 🤖 Manual / Auto-Remediation Run
  • 📅 תאריך ושעה של הריצה
  • ✅ מספר הצלחות   ❌ כשלים   ⏭ דילוגים
  • 🏢 Tenant ID מקוצר
  • ✅ CVE ID · שם המוצר (עד 10 פריטים)

התראות New CVE נשלחות גם כן כאשר Defender מזהה פגיעות שלא נראתה בסריקה הקודמת.

Security
identitymonitor.modernendpoint.tech/identity
🔒 Conditional Access

📋 רשימת מדיניות

כל מדיניות ה-CA נטענת בזמן אמת מ-Microsoft Graph. מציגה שם, סטטוס (Enabled / Disabled / Report Only), תנאים, תאריך עדכון אחרון ופעולות Enable / Delete.

⚡ Quick Actions

תבניות CA מוכנות לשימוש: חייב MFA לכל אדמינים, חסים Legacy Authentication, אכוף מכשירים תואמים — הפעלה בלחיצה אחת.

📍 Named Locations

צפייה וניהול של טווחי IP מהימנים ו-Named Locations לפי מדינה, המשמשים בתנאי ה-CA — ישירות מהפורטל.

🔑 דרישת הרשאה

נדרשת הרשאת Graph Policy.ReadWrite.ConditionalAccess. באנר מזכיר אם חסרה — עבור להגדרות ובקש Admin Consent מחדש.

  • ✅
    Enable — מעביר מדיניות Disabled/Report-Only לסטטוס Enabled
  • 🗑️
    Delete — מוחק לצמיתות מדיניות CA מ-Entra ID
  • 🔄
    Refresh — טעינה מחדש של רשימת המדיניות מ-Microsoft Graph
  • 📍
    Named Locations tab — מעבר לצפייה וניהול של טווחי IP מהימנים
  • ⚡
    Quick Actions tab — פריסת תבניות CA נפוצות בלחיצה אחת
⚠️ הפעלה או מחיקה של מדיניות CA משפיעה מיידית על האותנטיקציה של כל המשתמשים בארגון. מומלץ לבדוק קודם עם מצב Report Only לפני מעבר ל-Enabled.
